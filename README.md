# Smart Cube 3-style

A minimalist 3-style method trainer for bluetooth smart cubes.

# Getting Started

Use Node.js 20.19+ or 22.12+ and pnpm.

1. Install dependencies: `pnpm install`
2. Run the app: `pnpm start`
3. Open the app in your browser: `http://localhost:5173`

Click the `Connect` button to connect to your bluetooth cube.

Run `pnpm build` to build the static site into `dist/`, or `pnpm preview` to preview the build locally.
